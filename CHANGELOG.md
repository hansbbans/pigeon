# Changelog

All notable changes to Pigeon are documented in this file.

## [Unreleased]

### Fixed

- Starred now defaults to All so opening a saved story does not hide it.
- Website mode on iPad reloads when switching stories instead of keeping the previous page.
- Feed Content and Reader View start at the top (or the saved position for that story) when switching stories on iPad.
- Reader View / Website preferences follow a newsletter from For You into its feed.
- Opening a story without a web address no longer overwrites that feed's reader mode.
- Starring or unstarring from any list updates an already-loaded Starred list immediately.
- Marking a story Not Interested from Today or a feed drops it from an already-loaded For You list.

## [0.0.1.0] - 2026-08-16

### Fixed

- Newsletter feeds that use nested layout tables now display as a clean reading column, while genuine data tables retain readable borders and horizontal scrolling.
